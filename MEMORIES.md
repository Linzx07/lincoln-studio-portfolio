# Preferências do Lincoln para o portfólio

- Sempre que apresentar o site ou concluir uma atualização, enviar também o endereço completo da prévia pela rede local, no formato `http://<IP-local-atual>:8765/`.
- Antes de enviar esse endereço, iniciar a prévia do diretório `dist` na porta `8765`, conferir que ela responde pelo IP local e deixá-la ligada para Lincoln visualizar. O IP pode mudar; consultar o endereço IPv4 da rede a cada vez.
- Informar que a prévia por IP funciona para dispositivos na mesma rede local. Não usar `localhost` como endereço para Lincoln abrir em outro dispositivo.
- Para atualizações do site, continuar publicando e verificando o endereço de produção da Cloudflare conforme `AGENTS.md`, e enviar os dois links.
